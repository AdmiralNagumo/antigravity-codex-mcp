# Coordination design references

The integration keeps Antigravity responsible for interpreting intent, evaluating evidence and explaining outcomes. Codex retains technical investigation and implementation judgment. These projects were read as design references; their code and personal execution policies are not installed or copied wholesale.

| Reference | Applied idea |
| --- | --- |
| [lbc9168/antigravity-codex-worker](https://github.com/lbc9168/antigravity-codex-worker) | Native host skill, task-specific briefs, independent review and focused rework |
| [khanhbkqt/spawn-agent](https://github.com/khanhbkqt/spawn-agent) | Bounded tasks and distinct success, partial and failed reporting |
| [gitguffaw/codex-router](https://github.com/gitguffaw/codex-router) | Native host adapter over a common runtime, exact jobs, live capability discovery, host-aware waiting |
| [billythekidz/cli-agent-skills](https://github.com/billythekidz/cli-agent-skills) | Native session identity, durable handoffs and realistic continuation tests |
| [tolmachevmaxim/cli-agents](https://github.com/tolmachevmaxim/cli-agents) | Self-contained briefs, evidence checks and synthesis instead of raw logs |
| [bradleygolden/orchestrate](https://github.com/bradleygolden/orchestrate) | Proportional delegation, bounded reports and preserved user preferences |

The default remains one coordinator and one worker. There is no required fleet, fixed plan-approval ceremony, blanket sandbox bypass, global last-session resume, or claim of guaranteed host wake-up.
